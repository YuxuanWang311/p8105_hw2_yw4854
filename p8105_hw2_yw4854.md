This dataset contains information about NYC subway station and their
entrances and exits. The key variables include station information, such
as line and station name. Geographic location, such as station latitude
and station longitude. Routes served, entrance detial, and accessibility
status. For data cleaning, I first cleaned the column names using
`janitor::clean_names()` to make them easier to work with. Next, I used
`select()` to keep only the required variables. Then, I converted the
entry variable from character values into logical values using the
`case_match()` function. The resulting dataset has 1868 and 19 clomns.
But this dataset is not tidy. The main reason is that the route
information is spread across eleven different columns. To make the data
tidy, each route variable should be reshaped into a single column so
that each row represents a unique observation.

To clean the baseline demographic dataset, the first row containing
column descriptions was skipped during import, and missing values
represented by `.` were parsed as `NA`. Categorical indicators were
recoded: `sex` was converted to `male`/`female`, and `apoe4` status was
recoded to `carrier`/`non-carrier`. Participants who already had MCI at
or prior to baseline (`age_at_onset <= current_age`) were removed to
meet the inclusion criteria. A total of 479 participants were eligible
at baseline. Of these, 93 participants developed MCI during the
follow-up period. The average baseline age of the participants was 65
years. Among the female participants, approximately 30% were APOE4
carriers.

omitted from the baseline analysis, likely due to failing the baseline
